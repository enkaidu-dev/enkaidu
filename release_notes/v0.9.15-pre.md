
#### CHANGE

- The `Web` tools support host policies to control the servers / hosts that they can be used to access, with a change to the allow/deny lists behaviour as of this release.
  - Each of `http_get_web_page_as_markdown` and `http_get_web_page` support the following tool settings:
    - `allowed_hosts:` an array of host names that are always allowed, empty means none always allowed (default)
    - `denied_hosts:` an array of host names to always refuse to connect to, empty means none always denied (default)
    - `allow_private_hosts:` can be set to `true` allow access to private/local hosts, default is `false`
- The `exclude_past_reasoning` property, set via `session` or `llm:... model:...` settings, supports two values types:
  - If `true`, as before, all reasoning from past turns is excluded.
  - If a positive number of turns, then only reasoning from prior turns is excluded.
    - This allows you to preserve recent reasoning, only excluding from older turns.
    - A turn starts with a user input, and includes all tool calls and responses until next user input.

#### FEATURES

- The `Web` tools ask for user permission when a host is unknown (not allowed nor denied)
  - Each of `http_get_web_page_as_markdown` and `http_get_web_page` has their own allowed and denied lists
  - The permission options are to deny or allow once or always:
    - The terminal UI will present a four-letter choice: `a` to allow, `d` to deny, `A` to allow always, and `D` to deny always.
    - The web UI will present `Allow` and `Deny` buttons and a `[ ] Remember` checkbox allow or deny always.
- The web UI supports searching prompt history.
  - Use `Cmd-K` or `Ctrl-K` to open a search prompt and start typing to find matching past inputs.
  - `Cmd-R` or `Ctrl-R` also supported for terminal users who already reach for those shortcuts.
