
#### IMPROVEMENTS

- Support inline formatting for Markdown table rendering
- Support Ollama cloud-hosted models; expects your API key in the `OLLAMA_API_KEY` environment variable.
- Enhance the string replacement tool in the `TextEditing` toolset, to:
  - accept an `occurrence` parameter to pick which match to replace (default is `1`), or `-1` replace all all
  - return only the modified lines with information about the location of those lines. (instead of the entire modified file).
- Improve the `search_files` tool in the `FileManagement` toolset to support limits and return mat counts, skipped files etc.
- Improve `find_files` tool in the `FileManagement` toolset to support max matches per file.
- Revamp the UX design for Enkaidu's web UI mode, taking inspiration from Claude.
- Support one automatic retry when chat protocol connection fails on a post; after that, users can manually retry.

#### FIXES

- Fix to include a `Connection: keep-alive` header in LLM protocol requests.
- Fix so that Enkaidu detects when connection error causes prompt to fail and warns user, internally ensuring reconnection next time instead of holding on to failed underlying HTTP client.
- Fix so that markdown rendering doesn't swallow or mis-render non-table text with pipes.
