#### IMPROVEMENTS

- Enable configuring `think_map` inside `settings:` either on an individual LLM model or on the parent provider block under `llms:` (where models inherit provider settings and can override individual keys):
  - Consider the following example:
    ```yml
    llms:
      openai:
        provider: openai
        settings:
          think_map:
            max: xhigh
        models:
          - name: o3-mini
            model: o3-mini
            settings:
              think_map:
                none: ~
                max: ~
    ```
  - Each entry in `think_map` (`none`, `low`, `medium`, `high`, `max`) maps Enkaidu's canonical reasoning level to a model-specific wire string, or to `~` / `null` to mark that level as unsupported.
- Web UI's file, macro, and history picker improved:
  - Background blur replaced with a dark but clear view so promptbar content is clearly visible
  - Picker layout standardized with instructions along the bottom
  - Instruction text formatting improved for clarity
  - File picker modified so `Tab` is used to navigate into sub-folders while `Enter` commits whatever has been selected so far.
- Extend `?break if` and `?break unless` macro conditional commands to detect when the last prompt stopped due to an error:
  - A session now records `error` (in addition to `none`, `user`, and `tripwire`) as a prompt interrupt reason when an LLM or connection error stops a turn.
  - Macros can check `last_prompt_interrupt=error` (or `last_prompt_interrupt=any`, which matches `user`, `tripwire`, or `error`) to branch or exit accordingly.

#### FIXES

- Ensure that the chat/completions protocol handles rate-control responses via 429 and in-stream errors reporting too many requests properly.
- Fine-tune the rate-control error handling and ensure that underlying connections are closed between retries
- Decouple network-related errors (which drive retries) from rate-control error (which is handled) and all other errors (which should flow up and get reported).
- Improve resilience of Responses API streaming by allowing turns that finish cleanly with [DONE] to proceed even when proxies omit the `response.completed` event.
- Convert terminal LLM server and unexpected response error events into exceptions, and repair session history when a turn fails mid-flight so subsequent prompts do not fail due to unfulfilled tool calls or dangling user turns.
