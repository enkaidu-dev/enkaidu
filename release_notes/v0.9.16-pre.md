
#### CHANGE

#### FEATURES

* Support preview rendering for Draw.io XML diagrams using the `mxgraph` schema.

#### EXPERIMENTAL

#### IMPROVEMENTS

* In the web UI slash commands that produce helpful information (e.g. `/help` or `/tool ls`) present their content as auto-collapsing content cards and don't disappear into activity groups.
* Clearly indicate when the session is closed and browser tab can be closed after `/bye` command in the web UI.
* The `http_get_web_page_as_markdown` tool can optionally save the converted web page as Markdown to a file. This is useful when a web page is too long and gets truncated.
* The `http_get_web_page_as_markdown` and `http_get_web_page` tools support following redirects (viz. 301, 307, 308) up to a maximum of three times when fetching web content.

#### FIXES

* Fixed up/down navigation within web UI's multi-line prompt inputs so it doesn't navigate history up or down unless cursor is at first or last visual line respectively.
* Fix Mermaid diagram renderer in web UI to show errors instead of spinning in a loop causing browser tab to crash.
* Fix Vega-lite chart renderer in web UI to show errors instead of causing browser tab to crash.
* Fixed to show macro picker only when editing the macro name from prompt bar in web UI
* Fixed to show all tool calls in web UI's activity groupings
* Fixed to always send session ID using `x-session-id` request header, this is well known and recognized by all routers.
