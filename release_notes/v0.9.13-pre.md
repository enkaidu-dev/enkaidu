
#### FEATURES

- Add `azure_foundry` LLM provider type for Microsoft AI Foundry, supporting Open AI / chat completion models.
  - Expects API key via `AZURE_FOUNDRY_API_KEY` environment variable.
  - Expects the endpoint URI (no paths) via `AZURE_FOUNDRY_ENDPOINT` environment variable. E.g. `https://myproject.services.ai.azure.com`
  - Define LLM models in `enkaidu.yml` as shown in the following example:
    ```yml
    llms:
      azure-ai:
        provider: azure_foundry
        models:
          - name: az_gpt5_6luna
            model: gpt-5.6-luna
    ```
- Enable Web UI to detect when files are written or edited and show buttons for the files, and allow the user to click on the button to view the edited file.
- Allow profile configuration in `.enkaidu/config.yml` to include `session:` and `cordon:` sections, overriding those read from whichever `enkaidu.yml` you have.
  - You can now use a home `enkaidu.yml` with project-specific `session` and `cordon` settings
- Support `temperature` property for LLM model settings, either a number > 0 and <= 2, or default if not specified. For example:
  ```yml
  ollama:
    provider: ollama
    models:
      - name: glimmer
        model: muse-glimmer:30b-mxfp8
        settings:
          temperature: 1
  ```
